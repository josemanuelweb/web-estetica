# 🌿 PRO Estética - Sistema Inteligente de Gestión de Turnos

Sistema web desarrollado para la optimización de reservas en centros de estética, integrando validación lógica de datos y comunicación directa vía WhatsApp.

## 🚀 Características Principales
* **Gestión de Turnos Real-Time:** Panel administrativo con actualización automática cada 5 segundos.
* **Seguridad de Datos:** Acceso restringido al administrador mediante sistema de sesiones y login.
* **Integración con WhatsApp:** Generación automática de mensajes de confirmación para reducir el ausentismo.
* **Base de Datos Autolimpiable:** Algoritmo en Python que elimina registros obsoletos para mantener la eficiencia del almacenamiento (SQL).

## 🛠️ Tecnologías Utilizadas
* **Backend:** Python 3.12 + Flask
* **Base de Datos:** SQLite con SQLAlchemy (ORM)
* **Frontend:** HTML5, CSS3 (Diseño Responsive)
* **Lógica de Datos:** Procesamiento de objetos DateTime para validación de horarios comerciales.

Este proyecto aplica conceptos fundamentales de mi formación:
1. **Gobernanza de Datos:** Implementación de niveles de acceso (Login).
